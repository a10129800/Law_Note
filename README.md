### 📖 導論：犯罪概念與論罪結構
> *(教材第 XVIII-1 頁)*  
> **核心導讀**：踏入刑法的第一步！先建立犯罪概念（一個壞人做了一件壞事）與通說的三階層檢驗架構，再掌握論罪的五階流程。

  - **全章 16 大核心小節**（含案例 1-1 ～ 1-17）：
    - 阻卻罪責事由（精神障礙、年齡、不能防免之違法性錯誤、期待可能性）。
    - 阻卻違法事由（正當防衛、緊急避難、依法令行為、業務正當行為、被害人承諾、推測承諾）。
    - 三階層 vs 二階層體系檢驗、目的犯罪體系。
    - 全面配置「🗣️ 被告心聲自白」、「💡 白話文超展開專區」與「📢 記憶精華口訣」。
  - **十六、刑法核心爭點超級對照矩陣 (Mega Matrix)**：
    - 違法性 vs 罪責、防衛 vs 避難 vs 義務衝突、承諾 vs 同意三大維度對照。
- **第二章 刑法的論罪結構** *(教材第 1-13 ～ 1-16 頁)*：
  - § 12 故意既遂為原則，未遂犯 (§ 25)、過失犯 (§ 12 Ⅱ)、不作為犯 (§ 15) 例外處罰。
  - 處罰光譜與五階審查思考路徑。

    - 地的效力（屬地主義 § 3、隔地犯 § 4、屬人主義 § 6/§ 7、保護主義 § 5、世界主義）。

## 🎯 系統架構與技術特點

- **純原生現代架構（Vanilla HTML / CSS / JS）**：零第三方構建依賴，本地雙擊秒開，離線完全可用。
- **零 CORS 跨域限制（Zero-CORS Architecture）**：全站使用標準 `<script src="...">` 與 `<link rel="stylesheet">`，在任何瀏覽器直接點開 `file:///` 本地檔案即可完美載入。
- **單一真實來源（Single Source of Truth）**：以 [index.html](file:///e:/IDE資料/圖說刑法總則_專案/index.html) 為核心，章節視圖解耦模組化，維護不再怕漏改。
- **現代三欄自適應佈局（3-Column Layout）**：
  - **左欄（280px 毛玻璃浮動卡片）**：三層樹狀目錄，支援智慧自動折疊（Accordion），換章節時自動展開當前、收合其他。
  - **中欄（100% 全寬展開）**：主要研讀區，解除了 768px 寬度截斷瓶頸，卡片全寬緊貼右欄，閱讀舒適大器。
  - **右欄（220px 緊湊欄，支援一鍵收合）**：動態 TOC 目錄、研讀進度條與常用法條晶片，支援點擊一鍵收合展開全寬。
- **標準化 Draw.io 向量 SVG 流程圖規範**：
  - 13.5px 以上加粗字體、高對比色票與方格紙藍圖底紋。
  - 防拖曳機制（`draggable="false"` 與 `user-select: none`），操作滑順不黏手。
  - 支援「適配頁面」與「100% 原始大圖」雙檢視切換，並可點擊喚起全螢幕燈箱放大。
- **零重複原則（Zero-Redundancy Rule）**：圖表外不再羅列重複概念卡片，專注於「圖表 ➔ 白話導讀 ➔ 銜接章節」的順暢動線。

| **右側留白過大、卡片提早截斷** | CSS 曾硬性寫了 `max-width: 48rem !important` (768px)，使卡片提早截斷。 | 設為 `width: 100% !important; max-width: 100% !important;` 讓卡片填滿中欄。 |
| **流程圖文字模糊、拖曳殘影** | 使用點陣圖檔或未限制拖曳屬性，文字太小或拖曳時反白。 | 採用 Draw.io SVG 向量格式、字級大於 13.5px，並加入 `draggable="false"` 與 `user-select: none`。 |
| **圖外重複列出卡片導致冗贅** | 流程圖下方又把圖裡的文字原封不動拆成卡片再講一次。 | 遵循 Zero-Redundancy 原則，移除重複卡片，以「💡 白話文速讀專區」進行生活化比喻解析。 |
| **左側欄溢出覆蓋中欄** | 網格僅 260px 卻套用 `w-72` (288px)，且全部章節預設全展開。 | 左欄固定 280px 毛玻璃卡片，實裝智慧折疊樹（Accordion）只展開當前章節。 |
| **本機雙擊開啟失敗 (CORS)** | 用 `fetch()` 讀取本地檔案觸發瀏覽器同源安全性阻擋。 | 改用標準 `<script src="...">` 搭配全域物件掛載註冊（Zero-CORS）。 |
| **按鈕點擊無反應 (TDZ 報錯)** | 在控制器變數尚未宣告前就提前執行調用。 | 所有 DOM 節點變數一律頂置宣告，並在函式入口處動態檢查與刷新。 |
| **右側目錄掉落至頁尾** | 內文小節有多餘未閉合的 `</div>` 導致父容器提前閉合。 | 確保外層佈局容器嚴格維持 3 個一級子節點。 |
