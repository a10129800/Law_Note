## 🎨 排版視覺憲法與工程規範 (`AGENTS.md`)

* **重點標記「純紅底線」**：堅決杜絕刺眼的全紅文字，重點一律採用 `<span class="underline decoration-red-500 decoration-2 underline-offset-4 font-bold">`。
* **單欄垂直堆疊 (Strict Vertical Stacking)**：名師解析卡片嚴禁橫向並排擠壓（禁止 `grid-cols-2`），一律垂直向下排列 (`space-y-4`)，保障各螢幕尺寸具備最佳可讀性。
* **8px 實心側邊語意色軸**：
  * 🚨 **玫瑰紅邊框** (`#e11d48`)：違法高風險、構成要件該當、處罰要件。
  * 🌿 **翡翠綠邊框** (`#059669`)：阻卻違法、合法過關、免責事由、風險降低。
  * 🔷 **天藍邊框** (`#2563eb`)：客觀構成要件、通說體系、日常風險。
  * 🟪 **深紫邊框** (`#7c3aed`)：學說爭議、實務爭議、修法前沿。
* **零 CORS 本機秒開相容**：全站無任何本機 `fetch()` 跨域依賴，透過模組化腳本全域掛載，雙擊 `file:///` 即可直接秒開。

   - 雙擊開啟 [`index.html`](file:///e:/IDE資料/圖說刑法總則_專案/index.html)。

   - 瀏覽器網址列帶入 `#part2-ch2-sec1` 或點擊左側目錄 **「第二篇 ➔ 第二章 ➔ 第一節 構成要件行為」**，即可直接進入最新完結單元研讀。
