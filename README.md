## 🐣 小白看過來：30 秒搞懂這份筆記怎麼讀？（大白話版）

這份筆記專門用**日常生活的白話文**和**超有感生活比喻**，讓完全不懂法律的人也能 30 秒秒懂：

1. **🎨 顏色超顯眼、重點一秒看清**：
   - 不再是一片死白！每種法律原則都有自己的專屬高飽和色彩（天藍、深紫、暖橘、磚紅、翠綠）。
   - 左邊配置 8px 粗色邊條，**紅框代表「🚨 違法危險」**、**綠框代表「🌿 合法過關」**，瞄一眼就抓到核心。
   - **純紅底線規範**：重點關鍵字一律採用優雅的紅色雙線或下底線（`underline decoration-red-500`），避免刺眼的全紅字造成視覺疲勞。

2. **💡 法律文縐縐在講啥？生活情境神比喻**：
   - 🎲 **大富翁遊戲** ➔ **罪刑法定原則**：沒寫在遊戲說明書裡的規矩，不能事後找我扣錢算帳！
   - 🛖 **長老浸豬籠** ➔ **習慣法禁止**：不能拿民間習俗抓人坐牢，一定要立法院白紙黑字寫好才算數！
   - 🍔 **偷漢堡不是偷飲料** ➔ **類推禁止**：長得很像不代表是一樣的！偷電不能硬凹成偷第四台訊號。
   - 🏫 **學校機車校規** ➔ **罪刑明確性**：不能含糊寫「表現不好罰到主任滿意」，犯什麼罪、關幾年都要寫得清清楚楚。
   - 🕹️ **遊戲改版封號** ➔ **溯及既往禁止**：法律不能搭時光機，昨天沒說犯法的事，今天不能回頭抓昨天的我。

     - **宣告刑** ＝ 收銀台發票金額（法官審酌態度情狀敲定的唯一具體刑期）。
     - **執行刑** ＝ 最終付錢方式（多罪合併打折、分期、易科罰金或入監執行）。

### 📖 導論：犯罪概念與論罪結構
> *(教材第 XVIII-1 頁)*  
> **核心導讀**：踏入刑法的第一步！先建立犯罪概念（一個壞人做了一件壞事）與通說的三階層檢驗架構，再掌握論罪的五階流程。

- **第一章 犯罪的概念** *(教材第 1-1 ～ 1-11 頁)*：
  - **犯罪直觀本質**：壞事（不法）＋ 壞人（罪責）。
  - **全章 16 大核心小節**（含案例 1-1 ～ 1-17）：
    - 阻卻罪責事由（精神障礙、年齡、不能防免之違法性錯誤、期待可能性）。
    - 阻卻違法事由（正當防衛、緊急避難、依法令行為、業務正當行為、被害人承諾、推測承諾）。
    - 三階層 vs 二階層體系檢驗、目的犯罪體系。
    - 全面配置「🗣️ 被告心聲自白」、「💡 白話文超展開專區」與「📢 記憶精華口訣」。
  - **十六、刑法核心爭點超級對照矩陣 (Mega Matrix)**：
    - 違法性 vs 罪責、防衛 vs 避難 vs 義務衝突、承諾 vs 同意三大維度對照。
- **第二章 刑法的論罪結構** *(教材第 1-13 ～ 1-16 頁)*：
  - **故意既遂原則**：刑法以處罰故意既遂犯為原則（§ 12 Ⅰ）。
  - **四大例外審查階層**：未遂犯（§ 25）、過失犯（§ 12 Ⅱ）、不作為犯（§ 15）及結合犯。
  - **原書 1-16 頁犯罪基本審查流程圖**：手繪級向量 SVG 流程圖，五大步驟嚴密判斷。
  - **破除兩大思維誤區**：
    - 「非既遂 ≠ 即為未遂」：須先檢驗是否著手、是否具備法條明文罰未遂。
    - 「非故意 ≠ 即為過失」：過失以法有明文為限，主觀無故意且法未罰過失則根本不成立犯罪。
  - **實戰案例精解**：案例 2-1（失手打碎骨董花瓶）、案例 2-2（誤認鹽巴投毒殺人）、案例 2-3（溺水見死不救案）、案例 2-4（強盜致人於死加重結果犯）。

## 🎯 系統架構與技術特點

- **純原生現代架構（Vanilla HTML / CSS / JS）**：零第三方構建依賴，本地雙擊秒開，離線完全可用。
- **零 CORS 跨域限制（Zero-CORS Architecture）**：全站使用標準 `<script src="...">` 與 `<link rel="stylesheet">`，在任何瀏覽器直接點開 `file:///` 本地檔案即可完美載入。
- **全域多態無刷新視圖控制器（Multi-State View Controller）**：
  - 狀態 0：`#viewCover` 純淨封面（3D 立體書封引擎、元照規格校對、全寬導讀看板、自動隱藏右側 TOC）。
  - 狀態 1：`#viewChapter1` 第一章 犯罪的概念（全 16 節與十六大爭點超級矩陣）。
  - 狀態 2：`#viewChapter2` 第二章 刑法的論罪結構（四大審查階層、原書 1-16 向量流程圖）。
  - 狀態 3：`#viewPart0` 第零篇 刑法的運作原理（五位一體法學劇院、四大天王導師席、雙思維導圖）。
- **左側導航欄獨立滾動與小節預設折疊**：
  - 左側 `<aside>` 採用 `max-h-[calc(100vh-6rem)] overflow-y-auto custom-scrollbar`，高度限制防止溢出螢幕底部。
  - 所有小節 `<details>` 預設為收合狀態，保持樹狀目錄緊湊整潔。
- **單欄垂直堆疊規範（Strict Vertical Stacking）**：
  - 名師講評卡片嚴禁橫向並排（杜絕 `grid-cols-2` 壓迫感），一律採垂直向下排列，確保閱讀體驗舒適大器。

## ⚠️ 常見架構避坑指南 (Gotchas)

| 常見地雷 | 踩坑原因 | 正確解法 |
| :--- | :--- | :--- |
| **名師卡片橫向並排擠壓** | 使用 `grid-cols-2` 導致字級被迫縮小、閱讀擁擠吃力。 | 遵循 AGENTS.md 規範，嚴禁並排，一律採垂直單欄向下排列 (`space-y-3`)。 |
| **刺眼全紅字視覺疲勞** | 使用 `text-red-500` 全紅文字干擾閱讀專注度。 | 改用純紅底線標記：`<span class="underline decoration-red-500 decoration-2 underline-offset-4 font-bold">`。 |
| **心智圖點擊考點跳動** | 點擊 `(Q)` 按鈕觸發外部彈窗或跳轉至頁底錨點。 | 採用就地展開（In-place Expansion）機制，在畫布下方原位滑動展開。 |
| **本機雙擊開啟失敗 (CORS)** | 用 `fetch()` 讀取本地檔案觸發瀏覽器同源安全性阻擋。 | 改用標準 `<script src="...">` 搭配全域物件掛載註冊（Zero-CORS）。 |
| **右側目錄掉落至頁尾** | 內文小節有多餘未閉合的 `</div>` 導致父容器提前閉合。 | 確保外層佈局容器嚴格維持 3 個一級子節點。 |
