## 🎯 系統架構與技術特點 (符合 Ponytail 極簡哲學)

1. **純原生現代架構 (Vanilla HTML5 / Modern CSS / Vanilla JS)**：
   - 拒絕引入龐大的打包構建流水線（No Vite / Webpack / Next.js overhead）。
   - 代碼乾淨純粹，運行開銷極低，渲染性能極致流暢。
2. **零 CORS 限制本地秒開 (Zero-CORS Architecture)**：
   - 嚴禁在未配置 Web Server 時使用 `fetch()` 讀取本地 JSON/HTML 造成瀏覽器同源阻擋。
   - 使用標準 `<script src="...">` 掛載與全域物件註冊，雙擊 `file:///` 即可瞬間開啟全功能。
3. **單一真理來源視圖控制器 (Single Truth View Controller)**：
   - `switchView(view)` 全面納入 `cover`, `part0`, `part0-ch1`, `part0-ch1-sec1`, `part0-ch1-sec2`, `chapter1`, `chapter2`。
   - 麵包屑導航、側欄階梯按鈕高亮、右側 TOC 清單、標題徽章與 URL Hash 同步響應。
4. **側邊欄獨立滾動與小節預設折疊**：
   - `<aside>` 容器限制最大高度並套用細滾動條（`.custom-scrollbar`），防止溢出視窗底部切斷第零篇。
   - 所有小節 `<details>` 嚴禁帶有 `open` 屬性，預設收合保持目錄緊湊整潔。
5. **單欄垂直堆疊鐵律 (Strict Vertical Stacking)**：
   - 金毛點評與德牧雷達嚴禁使用 `grid-cols-2` 橫向擠壓排版，一律採垂直向下排列 (`space-y-3`)，保證在手機、平板與寬螢幕皆具備最佳字體行距與閱讀舒適度。
