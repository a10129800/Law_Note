# 歷史模組存檔區 (Legacy Modules Archive)

本目錄存放專案早期實驗性的視圖模組 (`content/*.js`) 與舊版控制器 (`js/app.js`)。

## 歷史背景說明
- 專案早期曾嘗試以 `index.html` 作為純外殼，並動態透過 `js/app.js` (舊版 2,386 行) 拼裝 `content/*.js` (17 個舊視圖檔案，1.34 MB)。
- 但在後續迭代中（四大天王特寫比例、五位一體法學劇院、赤狐女律師 vs 金毛大律師、邊牧 2026 最新定錨、純紅底線規範、雙心智導圖、Zero-CORS 本機秒開），所有最新最權威的內容與邏輯均已完全整合進 `index.html`。
- 舊版 `content/` 檔案缺少最新的赤狐律師言詞辯論、2026 年最新動態法條與新版路由，已被歸檔以防誤導。

## 最新架構 (2026-10)
- **結構**：`index.html`（單一事實來源 Single Source of Truth，支援 Zero-CORS 雙擊秒開）
- **樣式**：`css/app.css`（解耦樣式表，包含滾動條、字級、3D書封與動畫）
- **邏輯**：`js/app.js`（現代化控制器，包含資料驅動路由 `VIEW_CONFIG`、心智圖 SVG 生成器）
